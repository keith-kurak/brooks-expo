# Weekly challenge widget

Editable designs live on the
[Challenges Paper page](https://app.paper.design/file/01M06FKT4VGZT5BB9ST564VHEN/p-6-0),
below the mobile screen flow.

- `01-progress.png`: 3.2/5 km, 1.8 km remaining, two counted runs.
- `02-complete.png`: 5.4/5 km, earned badge, one drawing entry, three runs.

Both exports are 676×316, twice the 338×158 design canvas. Native sizes adapt
to the device. See [LLP 0008](../../llp/0008-us-run-club-promotions.research.md#weekly-challenge-widget)
for the proposed snapshot, deep-link and week-boundary behavior.

The entire widget opens Challenges. Enrollment and workout connection stay
in the app. The sample weekly goal and prize terms are illustrative.

Design reference: Apple's
[widget guidance](https://developer.apple.com/design/human-interface-guidelines/widgets?changes=la&language=objc).
No app code changed.
